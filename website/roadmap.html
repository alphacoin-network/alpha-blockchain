Alpha architecture — a Bitcoin-exact base layer carrying a deterministic meta-protocol stack, all validated by the same full nodes.

What's next — the remaining milestones

Mobile wallet — native iOS/Android apps wrapping the same self-custody key model as the web wallet (client-side keys, QR pay, biometric lock). The wallet protocol is already final; this is packaging work.

Staking & validators — Alpha stays proof-of-work; "staking" means an optional reward-lock layer where holders time-lock ALPHA via CLTV and earn a share of a community incentive pool — designed so PoW security is never replaced.

Stablecoin — a fiat-backed ALP token issued by a custodian with attestation records (the RWA infrastructure — KYC gating, backing proofs, clawback — is already live; what remains is the issuer/custodian integration).

Lightning-style channels — off-chain payment channels for instant low-fee transfers, settling to the base chain. Requires channel state machinery; HTLCs needed for it already exist (atomic swaps).
