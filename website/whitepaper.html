Abstract

Alpha Blockchain is a decentralized proof-of-work network engineered to Bitcoin's exact technical specification — SHA-256d PoW, 21,000,000-coin supply, 10-minute blocks, UTXO accounting, a full stack-machine Script engine, SegWit and Taproot — extended with a native token layer (ALP), SPV proofs, compact-block filters, PSBT, HD wallets and a complete explorer/REST API. It is designed to be permissionless, auditable and compatible with Bitcoin's well-understood security model.

1. Introduction

Alpha Blockchain re-implements Bitcoin's battle-tested design from first principles — a clean-room Python implementation with zero external dependencies — and layers the infrastructure needed for the next generation of applications: a deterministic token protocol (ALP), a block explorer, developer APIs and the plumbing for DeFi, identity, real-world assets and enterprise use. The goal: the security model developers already trust, with the tooling they actually need.

2. Consensus

  • Proof of Work: SHA-256d header hash ≤ compact target (nBits, 80-byte headers).
  • Difficulty retarget: every 2016 blocks, ±4× clamp, 10-minute spacing.
  • Median-time-past: 11-block median + 2-hour future limit.
  • Chain selection: most cumulative chainwork; full reorg support.
  • UTXO: deterministic set with coinbase maturity (100 blocks) and unique-txid rules.
  • BIP34: block height in coinbase; genesis reward unspendable (Bitcoin quirk).

4. Script & Contracts

A complete Bitcoin-style stack interpreter supports every standard locking script:

  • P2PK, P2PKH, P2SH, m-of-n multisig, OP_RETURN
  • CLTV (BIP65) & CSV (BIP112) timelocks
  • SegWit v0: P2WPKH / P2WSH / P2SH-P2WPKH (BIP141/143/144)
  • Taproot (BIP340/341/342): schnorr signatures, key-path and script-path spends, tapleaf merkle trees, control blocks, OP_CHECKSIGADD
  • Full sighash matrix: ALL/NONE/SINGLE/ANYONECANPAY (legacy + BIP143 + BIP341)

5. Tokens — the ALP protocol

Assets are issued on-chain via an OP_RETURN meta-protocol (Omni-style), so the base consensus stays untouched while a deterministic parallel indexer tracks balances.

  • Issue: createtoken — token_id = issuance txid
  • Send / transfer: sendtoken — balance moves between addresses
  • Mint (issuer-only) & burn: minttoken / burntoken
  • Registry & holders: listtokens, gettokeninfo, gettokenholders, gettokenbalance
  • Reorg-safe: per-block undo journal rolls back token state on reorgs
  • Anyone can build on it — sendopreturn embeds arbitrary project data

6. Network & Nodes

  • Wire protocol: Bitcoin-exact framing — magic, 12-byte command, sha256d checksum
  • Handshake: version/verack, sendheaders, sendcmpct (BIP152)
  • Sync: headers-first + getblocks + block/tx relay via inv/getdata
  • Compact blocks: short-ID reconstruction from mempool (BIP152)
  • Bloom filters: BIP37 filtered-block serving for light clients
  • Compact filters: BIP157/158 GCS filters (getblockfilter/getcfilters)
  • addrv2 (BIP155) + SOCKS5 proxy + Tor hidden service (.onion hosting)
  • Pruning & assumeutxo: keep-N block pruning + UTXO-snapshot fast sync

7. Wallet & Keys

  • Encryption: AES-256-CBC + SHA-512×25000 EVP_BytesToKey (encryptwallet/unlock/lock)
  • HD: BIP32 deterministic keys (xprv/xpub, hardened/normal, BIP39 seed)
  • Addresses: legacy, P2SH-segwit, bech32 P2WPKH, bech32m taproot
  • Signing: coin-select + change, SIGHASH_ALL for all script types, signmessage/verifymessage (ECDSA public-key recovery)
  • PSBT: create/fund/sign/combine/finalize + BIP380 descriptors

8. Security Model

  • Deterministic RFC6979 nonces (no nonce-reuse → no key leak)
  • Strict DER (BIP66) + low-S (BIP62) — signature malleability closed
  • Curve-validation on all pubkeys (off-curve rejected)
  • Cookie-auth RPC (bitcoind model), wallet file 0600, no eval/exec/pickle
  • All consensus bounds enforced (MAX_MONEY, negative outputs, double-spend, fee≥0)

9. APIs & Interoperability

  • JSON-RPC: ~65 bitcoind-compatible methods (chain, wallet, mining, tx, tokens, PSBT, descriptors, filters, estimatesmartfee…)
  • REST: /rest/chaininfo|block|tx|headers|mempool|utxo|tokens
  • Web/explorer API: /api/stats|blocks|block|tx|address|tokens|search
  • SPV: gettxoutproof / verifytxoutproof partial-merkle proofs
