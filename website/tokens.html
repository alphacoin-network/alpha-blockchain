Tokens on Alpha

Assets issued on-chain via the ALP protocol — anyone can create one with createtoken.

Contract address? ALPHA is the native coin of this chain — like BTC on Bitcoin, it has no contract address (contracts only exist for tokens on smart-contract platforms like Ethereum). For ALP tokens, the on-chain identifier is the Token ID below — it is the txid of the token's issuance transaction: alpha_cli createtoken "Name" decimals supply → token_id. That's the address/ID you reference in sendtoken, dexsell, ammcreate, etc.
