Common fixes

  • "Windows protected your PC" → More info → Run anyway (unsigned app, safe)
  • Node not syncing → check guide.html, restart alphad
  • Send fails "immature coinbase" → wait 100 blocks (~coinbase maturity)
  • Send fails "too large" → split into smaller amounts or use Consolidate (Options ▾)
  • AUSD mint → send ALPHA to reserve with memo AUSD-MINT:<amount>
